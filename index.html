Возможности

Всё, что нужно
для безопасности

От генерации паролей до биометрической аутентификации — CipherVault закрывает все потребности.

AES-256-GCM шифрование

Authenticated encryption всех данных. Ключи хранятся только в памяти, никогда на диске.

Passkeys / FIDO2

Создание passkeys через WebAuthn API. Биометрическая аутентификация на всех устройствах.

Генератор паролей

Случайные пароли, BIP39 passphrase, пресеты от PIN до Strong. Экспорт пресетов в JSON.

Здоровье паролей

Анализ слабых, повторяющихся и утёкших паролей. Оценка времени взлома и push-уведомления.

Кастомные поля

Текст, пароль, URL, email, телефон — добавляйте любые поля и шифруйте их вместе с записью.

Массовые операции

Ctrl+Click для выбора нескольких записей, массовое удаление, горячие клавиши для навигации.

Безопасность

Многоуровневая
защита

Каждый слой защищён. От шифрования данных до обнуления ключей в памяти.

Защита в памяти

3-проходное обнуление буферов (0x00 → 0xFF → 0x00). Ключи обнуляются при блокировке.

Secure Memory Guard

Constant-time сравнение

Защита от timing attacks. Все сравнения выполняются за фиксированное время.

CSPRNG · crypto.randomInt

k-anonymity

Проверка через HIBP API с SHA-1 префиксом. Полный пароль никогда не покидает устройство.

HIBP · SHA-1 prefix

Аудит-лог

HMAC-SHA256 подписи для целостности. Все действия записываются и зашифрованы.

HMAC-SHA256

Сетевая защита

Rate limiting (4→6→8→10), TLS, CORS только localhost, security headers.
